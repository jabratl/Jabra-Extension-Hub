Jabra Extension Hub v0.7.0 — Phase 4 UI Foundation

This update adds a bottom navigation foundation for Home, Installed, Import, Activity and Settings. Existing plugin management features remain: ZIP import, plugin open/details, export, favorites, search, sort/filter, removal and rollback.

Project guide: PROJECT_GUIDE.md

This package has passed source-script validation and XML parsing. It has NOT been verified with an Android Gradle build or on a physical device. Full Material 3 light/dark palettes, tablet/landscape two-pane layout, true extension enable/disable lifecycle, reload controls, and automatic chapter glossary detection remain follow-up work and are documented in PROJECT_GUIDE.md.
