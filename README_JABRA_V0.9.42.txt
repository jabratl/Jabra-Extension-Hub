Jabra Extension Hub v0.9.42 (code 62)

What is new since 0.9.38:
 - Subtitles download with the video, named "<video>.en.vtt" (Plex / Jellyfin match them).
 - Media settings: find media on pages, library names, stream quality, wait between downloads. Open it from Browser menu, Settings > Media, or long-press the Media Browser tile on Home.
 - Home has a Media Browser tile; Settings has a Media section.
 - Share a link: the "Send link to" list can scan it in the Browser found list.
 - Plugins can read the Hub media settings (JabraAPI.mediaPrefs); plugin batches use the saved stream quality.
 - Found list: on narrow phones Download is an icon so "N selected" stays readable.
 - Fix: build error "Unresolved reference: ThemeStore"; plugins now get the phone's light/dark theme.
Media Grabber plugin 1.4.5 is a separate zip.
